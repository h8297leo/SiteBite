# Phase 1 交付與驗收紀錄

版本：`0.1.0-phase1`，2026-10-12（Asia/Taipei）。本次僅 Phase 1；等待使用者明確通過後再進入 Phase 2。

## 完成功能

- 原 ZIP 完整解壓、功能／問題 A/B/C/D 盤點；原始資料保留，獨立新目錄。
- React／TypeScript／Vite＋Node／Express，同一 `dev` 指令啟动同源前後端。
- 複用原始 SVG 雷達和深色 CSS，保留 SiteBite 品牌、卡片、詳情、手機／桌面、地圖／列表切換。
- 免金鑰 Photon 地點解析、來源選項消歧、座標輸入及基礎附近 POI 搜尋；Overpass 備援。
- Leaflet＋OSM 圖磚、搜尋中心、真實結果標記、GPS位置、縮放、popup、點卡片定位、基本篩選同步。
- 每筆地點來源、直線距離、10筆分頁、Google Maps 導航；不生成未知評分、熱門或私房分數。
- Zod 雙層格式／座標驗證、取消／序號防止舊回應覆蓋、逾時／重試／節流／快取、整頁及地圖獨立 ErrorBoundary、圖磚失敗訊息。

## 可操作預覽／啟動狀態

http://localhost:3000 。交付時前後端正在運行，只綁定本機127.0.0.1，沒有公開部署網址。已在 Codex 內建瀏覽器打開並保留預覽頁籤。

啟動環境中 `GEMINI_API_KEY`、`GOOGLE_MAPS_API_KEY`、`GOOGLE_SEARCH_API_KEY`、`GOOGLE_SEARCH_CX` 皆設為空白；新程式也完全沒有這些環境變數依賴。健康 API 回報 `apiKeysRequired:false`。

若程序停止，在 `sitebite-web` 執行 `npm install`／`npm run dev`；此電腦的內建 runtime 可以使用 `./start-local.ps1`。詳見 README。

## 尚未完成及外部限制

完整Phase 2–6功能尚未完成：漸進式擴張、所有 Provider 契約、多來源候選池與實體去重、所有時段／特色／價格／深入搜尋、全網文章與評論、當地語言查詢、跨平台評分、社群與私房熱門分析、完整診斷及全面穩定性驗收。

Phase 1 後端探索固定3km，前端預設沒有額外距離上限；不可解讀為無限全球擴張。Photon 本次最多回50候選，不保證每個地點都有完整名稱／地址或最新營業狀態。沒有可靠評分時評分篩選會是空結果。

公共服務有容量與可用性限制，本次主Overpass曾504、private.coffee鏡像曾500；Photon可用但不保證未來不中斷。採小量手動查詢、快取與節流，無自動完成、無背景爬取、無圖磚預抓。政策與來源連結記於README。

原版首次黑屏未取得原錯誤堆疊，無法誠實宣稱唯一歷史根因已重現；已識別未驗證回應、地圖座標／評分例外、無ErrorBoundary與過期回應風險，新版首次真實搜尋和錯誤恢復實測均通過。詳見原始盤點。
