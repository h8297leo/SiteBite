# Phase 2 修改前實際搜尋基準

完整 HTTP 回應、來源執行狀態、地點與來源證據保存在 `PHASE2-BASELINE.json`。測試以仍在執行的 0.2.0-core 後端完成，未使用模擬 Provider。搜尋位置來自 `/api/resolve`；測試者明確選擇預期國家的來源位置，沒有自行注入座標。

共取得16個雙模式實際搜尋回應，另保留3筆中文輸入解析失敗紀錄。後三項的英文重試為**測試者操作**，不能宣稱修改前應用程式具備自動翻譯能力。

所有回應的模式一致、距離由近到遠、沒有直接注入搜尋中心、評分與熱門／私房分數皆為 null。這些是程式檢查結果，不代表完成每個場所的人工現地驗證。

本輪 Overpass 在多個景點／城市案例發生逾時、記憶體限制、429及冷卻失敗。Wikipedia／Wikivoyage 保留部分地點。觀光署 ZIP 仍回傳自動存取封鎖，沒有繞過。不同地區的數量不能被解讀成地點資料的完整度，也不可以和不同時段成功率混為一談。

修改後比較會同時呈現搜尋中心變化、可見OSM筆數、新來源候選／驗證／加入池／加入最終結果、同店額外證據、來源失敗率與耗時。上限50及外部來源狀態會影響可見數量；新增地點應以來源貢獻追蹤與實際獨立場所證據判斷。
