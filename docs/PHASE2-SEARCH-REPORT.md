## 限制與驗收範圍

- 通用 SearXNG 未設定明確允許自動查詢的實例；DuckDuckGo 未宣稱可用。Wikipedia 關鍵字是限定百科的全文搜尋，Wikivoyage 是限定旅遊網站的文章搜尋，不能冒充全網搜尋。
- 任意地方美食／旅遊文章清單目前為選配擷取介面；未配置來源不算已整合。陌生 JSON-LD 自報座標須獨立地理驗證；不會只以文章標題生成場所。
- Wikidata 實體紀錄不是 HTML 網頁；診斷的網頁數不包含這些實體數。NYC 官方資料回應以一個資料文件計算，不把800筆紀錄說成800個網頁。
- 觀光署ZIP仍限制自動存取；沒有繞過。Overpass 的逾時／429／冷卻可能使某地餐飲結果不足或為0；保留真實診斷與已完成來源。
- 舊版首爾／巴黎／紐約中文輸入失敗後使用測試者英文重試；修改後原始輸入解析結果及所有替代位置完整保存在紀錄中。東京修正前後搜尋中心不同，因此結果差異不能全歸因於新來源。
- 名稱、分類及距離檢查皆為程式檢查，不等於每一場所的人工現地確認；未取得評論時所有分數為 null。
- 首次執行時網站尚未啟動的8筆連線失敗單獨保存在 `PHASE2-STARTUP-NOT-READY.json`，不納入公開來源失敗率。
